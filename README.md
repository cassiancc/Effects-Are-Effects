# Effects Are Effects

<a href='https://modrinth.com/mod/effects-are-effects/versions?l=fabric'><img alt="fabric" height="56" src="https://raw.githubusercontent.com/intergrav/devins-badges/refs/heads/v3/assets/cozy/supported/fabric_vector.svg"></a>

## Features

26.4 introduced the new **Freezing** effect, but its only use is on the new Ice Balls. This mod makes the Freezing effect also be applied by Powder Snow, and additionally adds a status effect for **Burning**, so players have an indicator on how long they will burn for.

## Installation

Effects are Effects is a client and server mod. It has no dependencies, as it includes the necessary Fabric API modules for the mod to work.

## FAQ

- **Will this mod be ported to other versions/loaders?**
    - I'm considering backporting this to the rest of 26.x, including a backport of Freezing. This will likely happen after the release of 26.4 after the implementation of Freezing is finalized. I have no plans to backport it further.
