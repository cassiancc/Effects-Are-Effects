# Embers and Icicles

<a href='https://modrinth.com/mod/embers-and-icicles/versions?l=fabric'><img alt="fabric" height="56" src="https://raw.githubusercontent.com/intergrav/devins-badges/refs/heads/v3/assets/cozy/supported/fabric_vector.svg"></a>

## Features

- The **Freezing** effect introduced in 26.4 is now applied by Powder Snow.
- A status effect for **Burning**, so players have an indicator on how long they will burn for.
- On versions below 26.4, the Freezing effect and Ice Balls are backported.
- By default, Ice Balls are now dropped when mining Ice without Silk Touch.

## Installation

Embers and Icicles is a client and server mod. Its dependencies are listed below.

- [Fabric API](https://modrinth.com/mod/fabric-api) is required on Fabric.

## FAQ

- **Will this mod be ported to other versions/loaders?**
    - I'm considering backporting this to the rest of 26.x, including a backport of Freezing. This will likely happen after the release of 26.4 after the implementation of Freezing is finalized. I have no plans to backport it further.
